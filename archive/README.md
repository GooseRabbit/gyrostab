# Архив старой реализации

Здесь хранится прежний экспериментальный скетч `gyro.cpp`.

Он сохранён для истории и возможного обращения к отдельным наблюдениям, но:

- не является основой новой прошивки;
- его настройки осей, знаков, DMP, частот и PWM не считаются подтверждёнными;
- найденные в нём решения нельзя переносить без повторной проверки;
- новая реализация проектируется по документам в `docs/`.

Старый файл не удалён из истории — он перемещён в архив текущего дерева репозитория.
